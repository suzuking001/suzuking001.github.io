Based on real automotive production engineering experience, I build browser-based factory simulation and discrete-event simulation tools for manufacturing engineers.

Main Projects

FactSim

FactSimは、製造ライン、設備、搬送、AGV、バッファ、ボトルネックを検討するための Webベースのファクトリーシミュレーションツールです。 ブラウザ上で動作し、タイミングチャートやCSV出力により、 ラインがタクトを満たすか、どこで詰まるかを確認できます。

Live Demo / GitHub Repository

fact_sim_mcp

FactSimを外部から制御するためのMCPサーバーです。 シミュレーション条件の変更、実行、検証、自動最適化に向けた実験環境として開発しています。

GitHub Repository

sim2exl

FactSimから出力したCSVをExcelに取り込み、 ノードごとの状態遷移をタイムチャートとして表示するVBAツールです。

GitHub Repository
